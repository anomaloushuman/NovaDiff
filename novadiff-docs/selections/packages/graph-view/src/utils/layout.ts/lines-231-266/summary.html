What it doesmergeElkPositions takes an array of graph nodes (nodes) and an ElkInput result (positioned) that contains layout coordinates from the ELK layout engine. It returns a new array of nodes where each node’s position (and optionally width/height for containers) is replaced with the coordinates supplied by ELK. If ELK did not provide a position for a node, the original node is returned unchanged, defaulting its position to {x:0,y:0} if missing.

How it works1. Build a lookup map

Each child from positioned is stored by its id with its coordinates and optional size.2. Map over the original nodesFor each node, it looks up the ELK result. If found, it replaces the node’s position with the ELK coordinates and, for container nodes, copies back the width/height that ELK echoed. If not found, the node is left untouched except for ensuring a default position.
