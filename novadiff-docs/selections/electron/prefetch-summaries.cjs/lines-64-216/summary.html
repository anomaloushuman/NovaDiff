What it doesrunSummaryPrefetchLoop orchestrates a background pre‑fetch of per‑file summaries for a diff. It receives a configuration object (opts) and an AbortSignal. It first calls runCompareEngine with the prefetch-summary-queue command to obtain a plan of files to process, then emits a summary-prefetch-progress event with initial statistics (jobs count, skipped counts, eligible changes). For each job it fetches the file diff via runCompareEngine (get-file-diff), builds diff chunks, constructs a payload for the LLM, calls summarizeChange, stores the result in summaryByPath, and optionally writes artifacts to rightRoot. Progress updates are sent after each file, and errors are reported with specific reasons (e.g., binary/non‑text). The loop respects signal.aborted to stop early. Finally, it emits a finished event indicating completion or abortion.

  • – Catches exceptions, distinguishes binary/non‑text skips, emits file-skipped or file-error.5. *Finish
  • – Sends finished event with aborted flag.
