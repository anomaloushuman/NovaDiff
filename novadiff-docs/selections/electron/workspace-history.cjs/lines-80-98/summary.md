### What it does`ensureCommitSnapshot` guarantees that a snapshot image exists for a specific commit hash in a workspace. It returns an object containing the snapshot path and a `ready` flag. If the workspace or snapshot path is missing, it throws an error.### How it works1. **Workspace lookup** – Calls `getWorkspace(userData, workspaceId)` and aborts with `"Workspace not found"` if the result is falsy.2. **Destination validation** – Resolves `snapshotPath` (or empty string) to an absolute path, trims it, and throws `"Snapshot path is required"` if the result is falsy.3. **Snapshot creation** – Invokes `snapshotCommit(workspace.repoRoot, hash, dest)` to generate the snapshot, storing the returned path in `snapPath`.4. **Commit list handling** – Normalises `workspace.commits` to an array, then finds the index of the commit whose `hash` matches the supplied `hash`.5. **Update commit record** – If found, sets that commit’s `snapshotPath` to `snapPath`, re‑assigns the updated array to `workspace.commits`, and persists the workspace via `upsertWorkspace(userData, workspace)`.6. **Return value** – Always returns `{ snapshotPath: snapPath, ready: true }` after the optional update.### Notes for reviewers- The function silently ignores commits that are not present in `workspace.commits`; no error is thrown in that case.- `snapshotCommit` and `upsertWorkspace` are external dependencies; their side effects (e.g., file I/O, database writes) are not visible in the snippet.- The function assumes `workspace.repoRoot` is a valid repository path; if it is invalid, `snapshotCommit` may fail, but that error is not caught here.- The returned `ready: true` flag is always true; the function never signals a pending state.
